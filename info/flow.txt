모임 생성 → 링크 초대 → 개인 조건 확인 → 메뉴 소거 → 식당 합의 → 방문 → 매장 화면 연결
① 모임 생성
방장이 날짜·시간·모일 장소·예산·식사 방식을 설정하고 초대 링크를 공유

② 참가 및 개인 조건 확인
기존 앱에서 사용자 조건을 바탕으로 메뉴 조건 확인

③ 지도에서 주변 식당 확인
현재 위치 또는 지정한 약속 장소 주변의 식당을 보여줘. 식당을 누르면 메뉴·가격·남은 선택지를 확인할 수 있음

④ 먹기 싫은 메뉴 제외
메뉴 카드에서 제외하거나 복구. 이유는 선택적으로 입력
예: 오늘 안 당김 / 가격 / 재료 / 맵기.

⑤ 결과 확인 및 식당 확정
전원이 ‘검토 완료’를 누르면 조건에 맞는 식당을 지도에서 강조. 한 곳을 제안하고 전원이 확인하면 확정
아무것도 누르지 않은 사람을 찬성으로 처리 x

⑥ 방문 후 키오스크 연결
휴대폰의 확정된 모임 화면에서 ‘키오스크에 적용’을 누르고, 해당 키오스크의 QR을 스캔
모임을 다시 선택하지 않고, 이미 확정한 결과를 전달?

⑦ 개인화된 메뉴 선택
키오스크에 모임 조건에 맞는 메뉴를 표시하고, 선택 완료 후 일반 메뉴 화면으로 초기화
