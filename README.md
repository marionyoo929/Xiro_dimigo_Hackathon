# 시로 개발 작업 폴더

원본 소스는 `dimigo_Hackathon-main.zip`, 실제 개발·실행 폴더는 `dimigo_Hackathon-main/`입니다. ZIP은 원본으로 보존했습니다.

```powershell
cd .\dimigo_Hackathon-main
npm.cmd ci
npm.cmd run dev
```

사용자·초대·매장 QR·사장님 화면은 모두 [로컬 앱](http://localhost:5173)에서 이용합니다. 개발 서버와 API 서버가 함께 실행됩니다.

[실행 및 설정](dimigo_Hackathon-main/README.md), [구현 결과·검증·남은 운영 작업](dimigo_Hackathon-main/docs/IMPLEMENTATION.md)을 확인하세요.
