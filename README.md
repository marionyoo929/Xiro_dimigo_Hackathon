# 시로 개발 작업 폴더

원본 소스는 `dimigo_Hackathon-main.zip`, 실제 개발·실행 폴더는 `dimigo_Hackathon-main/`입니다. ZIP은 원본으로 보존했습니다.

```powershell
cd .\dimigo_Hackathon-main
npm.cmd ci
npm.cmd run dev
```

사용자·초대·매장 QR·사장님 화면은 모두 [로컬 앱](http://localhost:5173)에서 이용합니다. 개발 서버와 API 서버가 함께 실행됩니다.

Node.js 24 이상을 사용합니다. 새로 받은 프로젝트는 처음 실행할 때 안산 중앙역 주변 식당 7곳·메뉴 90개와 최근 30일의 주문/음식 검토 통계 자료를 자동으로 생성합니다. 실행 중인 개인 DB나 로그인 세션을 전달받을 필요가 없습니다. 게스트로 시작하면 사용자 시연을, 이메일 로그인 창의 **사장님 시연 시작**을 누르면 매장 관리와 통계를 확인할 수 있습니다.

시연 순서: 게스트 시작·기본 정보 입력 → 파티 생성 → 다른 브라우저로 초대 참여 → 음식·식당 소거와 확정 → 사장님 화면에서 선택 매장 QR 발급 → QR로 매장 연결 → 각자 메뉴 선택 → 주문 제출·사장님 수락. 사장님 **통계**에서는 3일·일주일·한 달의 인기 카테고리와 소거 후 살아남은 대안 상위 5개를 확인합니다.

지도 검색은 이 폴더의 `.env.example`을 참고해 `.env.local`에 카카오 JavaScript 키를 설정합니다. 키가 없어도 안산 중앙역 1번출구 바로 선택으로 시연할 수 있습니다. 휴대전화의 실시간 카메라 스캔은 HTTPS에서 사용하고, 카메라를 사용할 수 없으면 **QR 사진 선택**을 사용합니다.

[발표용 개발 예상 질문과 모범 답안 16개](dimigo_Hackathon-main/docs/발표_개발_예상질문.md)도 함께 제공합니다. 릴리스 검증: API 테스트 22개, 브라우저 시나리오 23개, TypeScript·Vite 빌드 통과.
